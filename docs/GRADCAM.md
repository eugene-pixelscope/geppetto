# Detection Grad-CAM

모델 → 오류 분석 → **Grad-CAM · 모델이 집중한 영역**에서 완료된 가중치와 검증/테스트 이미지를 선택합니다. 입력 크기와 검출 후보 순위를 설정하고 내용 해시를 확인한 뒤 계산합니다. 기존 Kubernetes Agent가 GPU 1개를 할당하며 결과는 원본 모델에 연결된 진단 실행으로 저장됩니다. 새 모델 등록이나 학습은 하지 않습니다.

현재 검증 범위는 등록된 공 탐지 모델의 YOLO11/YOLO26 Detect/Pose 헤드, 공 클래스 0입니다. 일반적인 다른 모델 구조에는 해당 모델의 출력·대상 점수에 맞는 어댑터가 필요하며 지원되지 않는 구조는 오류로 종료됩니다.

- 실제 모델을 eval/FP32로 직접 호출하고 autograd를 활성화합니다. 추론 전용 `predict()` 래퍼는 사용하지 않습니다.
- YOLO11은 IoU 0.7 NMS 후, YOLO26은 one-to-one 헤드의 점수 순으로 후보를 선택합니다. 최대 상위 3,000개 후보에서 순위 1–20을 선택할 수 있습니다. 낮은 점수의 후보도 설명할 수 있으므로 검출 성공과 구분해야 합니다.
- 선택한 후보의 **NMS 이전 클래스 logit**을 해당 피라미드 레벨의 탐지 헤드 입력 특징 맵에 역전파합니다. 공간 평균 gradient를 채널 가중치로 삼아 가중합에 ReLU를 적용하는 [Grad-CAM 원 논문](https://arxiv.org/abs/1610.02391)의 방식입니다. 박스 회귀나 정답과의 매칭 점수는 대상 함수에 포함하지 않습니다.
- Letterbox 패딩을 제거한 뒤 원본 이미지 크기로 복원합니다. 이미지 로딩·합성은 RGB이며, 색상은 노랑→빨강, 무기여 영역은 투명합니다. 대상 후보의 박스는 하늘색입니다.
- 양의 신호가 없으면 지도를 만들어 내지 않고 그 상태를 표시합니다. 표시값은 이미지별 최댓값으로 정규화되어 서로 다른 이미지의 절대 기여도를 비교할 수 없습니다. Grad-CAM은 모델의 클래스 점수에 대한 설명이며 인과 증명이나 정답 마스크가 아닙니다.

원본, 투명 히트맵, 합성 PNG, 정규화된 float32 NPY, 대상/레이어/점수/gradient 크기/원본 및 패딩 크기/가중치·이미지·데이터 해시를 담은 JSON을 저장합니다. 화면에서 불투명도를 조절하고 합성 PNG/NPY/JSON을 내려받을 수 있습니다.

실행 전 원본 가중치와 선택 이미지의 SHA-256을 고정하고 Agent에서도 다시 검증합니다. 실행 이미지 digest, PVC UID 및 데이터 버전도 동결합니다. 진단은 선택한 이미지의 내용만 확인하므로 전체 데이터셋 평가나 전체 성능 지표를 생성하지 않습니다. 실행 요청은 확인 해시와 멱등 키를 사용합니다. 삭제된 모델에는 새 진단을 생성할 수 없습니다.

기존 **오류 위치 분포**는 GT/예측으로 집계한 별도 기능이며 Grad-CAM과 구분됩니다.
