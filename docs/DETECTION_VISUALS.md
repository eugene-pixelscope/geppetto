# 그래프와 detection 시각화 (0.3.4)

- 스칼라 및 비교 그래프 X축은 Epoch로 고정한다. 과거 로컬 저장소의 Step/Relative time 선택은 무시한다. Epoch가 없는 관측을 임의 변환하지 않으며 원본 최근 수치는 카드에 유지한다.
- 검증된 기존 YOLO26x 평가 실행의 `training_history/*`는 compare_mlflow.py가 CSV의 실제 epoch를 MLflow step으로 기록하므로 동기화 시 해당 값만 epoch로 연결한다. 다른 평가 단일 지표에는 epoch를 추정하지 않는다.
- 오류 히트맵은 미탐 정답/오탐 예측의 중심 위치 누적 분포다. 128×72 위치 집계에 Gaussian smoothing을 적용하여 연속적인 색으로 표시한다. Grad-CAM 또는 모델 활성화 지도가 아니다. 카메라별 원본 참조 프레임 위에 표시하며 여러 카메라를 섞은 상태에는 공통 원본 배경을 표시하지 않는다.
- 밀도는 현재 선택 조건에서 상대 강도이며, 국소 비율은 평활화된 오류 수 / 평활화된 해당 표본 수(정답 또는 예측)이다. 배경 면적 대비 FP율이나 mAP가 아니다. 히트맵 클릭은 기존 8×8 영역별 실패 샘플 조회로 연결된다. 히트맵 집계 자체는 실패 목록의 페이지/영역 선택에 의해 잘리지 않는다.
- SVG 박스 색은 RGB CSS 색상이며 BGR 변환을 사용하지 않는다. 정답은 미탐 여부와 관계없이 초록 실선이다. 미탐은 바깥 빨강 점선과 FN으로 추가 표시한다. 예측은 파랑 점선, 오탐은 주황 점선과 FP이다. 썸네일과 확대 뷰어는 같은 렌더러/팔레트를 사용한다. 정답을 예측보다 나중에 그려 겹친 예측에 초록이 가려지는 것을 줄였다.

태그와 생성 기록으로 확인한 검증용 실행 18개(모델 14개)를 기존 모델 삭제 기능으로 목록에서 정리했다. 실제 원본 실험과 파일은 보존한다. 대상 및 결과: `sample-cleanup.json`. 운영 카탈로그에는 시각화 검증용 합성 실험을 추가하지 않았다.

검증: `tools/browser_detection_visuals.py`, `tests/detection-visuals.mjs`, `tests/test_error_analysis.py`.

실제 모델 활성화 기반 시각화는 [Grad-CAM](GRADCAM.md) 패널에서 제공합니다. 오류 위치 분포와 별개입니다.
