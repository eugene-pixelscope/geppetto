TensorBoard Scalars UI를 참고해 원본(옅은 선)과 스무딩(진한 선)을 겹쳐 표시한다. Smoothing 0–0.99, 기본 0.6, 편향 보정 EMA를 사용한다. 지표 저장값은 변경하지 않으며 y축은 원본과 스무딩 값을 모두 포함한다. 툴팁은 Run/Smoothed/Original/축값을 표시한다. 설정은 브라우저 localStorage에 보존한다.
참고: https://www.tensorflow.org/tensorboard/scalars_and_keras
검증: `node tests/charts.mjs`, 실제 기록의 개별/프로젝트 비교 그래프, 모바일, 설정 유지, 키보드·툴팁 확인.
