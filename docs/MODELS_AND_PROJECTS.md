# 모델과 프로젝트

- 고래 = 실행 노드. 기본 이름은 실제 hostname(`local`, `mlops`)이며 사용자가 이름을 변경할 수 있다. 표시 이름 변경은 Kubernetes nodeName이나 UID를 바꾸지 않는다.
- 피노키오 = 개별 모델 하나. `model_id == pinocchio.id`로 식별한다. 이름이 같은 YOLO26 P2 모델도 서로 다른 ID를 가진다.
- 템플릿 = 모델을 학습하는 설정/실행 방법. 여러 모델이 같은 템플릿을 사용할 수 있다.
- 프로젝트 = 동일 과제의 모델과 실행을 비교하는 공간. 기본 공 탐지/등번호 탐지/등번호 인식 프로젝트가 있고 같은 분류의 새 프로젝트를 만들거나 모델을 옮길 수 있다. 프로젝트는 특정 고래에 종속되지 않는다.

## 모델 수명

처음부터 새로 학습하거나 기존 가중치로 새 학습(initialize)을 시작하면 별도 모델이다. 기존 모델의 resume/evaluate는 원래 모델을 유지한다. 반복 예약의 독립 실행들도 각각 별도 모델이다. 기존 피노키오에 독립 학습이 여러 개 묶여 있었다면 각 모델로 분리하고, 명시적인 부모를 가진 평가/재개는 원본 모델에 연결한다. 과거 frozen 설정은 수정하지 않는다.

이름 변경은 표시 메타데이터만 수정한다. 자동 수집과 Agent 갱신은 사용자가 변경한 이름을 덮어쓰지 않는다. 숫자로 부여한 기존 기본 이름은 모델/노드 이름으로 이전한다.

## 비교

프로젝트 페이지에서 최대 6개 실행을 선택하고 두 그래프에서 지표, step/epoch/경과시간, 스무딩, 범위를 선택한다. 그래프 선택은 페이지 자동 갱신 시 유지된다. 설정 차이는 기존 전체 작업 비교 화면에서도 확인할 수 있다.

MLflow `training_history/` 접두어가 붙은 원본 학습 지표는 그래프에서 접두어를 제거해 현재 학습 지표와 같은 축에서 비교한다. 원본 저장 키는 그대로 보존한다. `evaluation/` 재평가와 `checkpoint/` 기록은 서로 합치지 않는다. 재평가 결과 한 점을 학습 곡선으로 만들거나 없는 epoch를 추정하지 않는다. 기록이 없는 모델/축은 미기록으로 표시한다.

YOLO11x·YOLO26x 재평가는 과거 test-as-val 분할이며 현재 P2는 timestamp 분할이다. 데이터 버전/평가 조건이 다르거나 미확인인 경우 경고한다. 다른 프로젝트·작업 분류의 실행은 API에서도 비교를 거부한다. 서로 다른 아키텍처 loss를 성능 순위로 사용하지 않는다.

W&B의 프로젝트 workspace에서 실행을 선택하고 지표·설정을 비교하는 구성을 참고했다: https://docs.wandb.ai/models/app/features/panels/run-comparer . 외부 W&B 계정이나 데이터 전송은 추가하지 않았다.

## 모델 화면

피노키오를 선택하면 대표 실행의 지표·진행·결과 상세가 바로 열린다. 실행 선택을 위한 중간 학습 이력 페이지는 없다. 대표 실행은 진행 중 학습 → 최근 학습/재개 → 평가만 있는 모델의 최근 평가 순서로 선택한다. 이름/프로젝트 변경은 실행 상세에 있다. 다른 재개/평가 기록이 있을 때만 접힌 관련 실행 영역을 제공한다. 미학습 모델에는 첫 학습 시작 화면을 표시한다. 기존 피노키오 주소는 대표 실행으로 연결된다.

## 편집과 그래프 탐색

상단 오른쪽 연필은 표시 이름 편집, 톱니바퀴는 설정이다. 고래 카드 오른쪽에도 같은 버튼을 제공한다. 표시 이름은 목록/상세/경로/연결 노드 표에 반영하며 원래 hostname은 설정에서 별도 표시한다. Agent snapshot은 표시 이름을 덮어쓰지 않는다. 모델 설정에서 프로젝트를 변경한다.

그래프는 로컬에 포함한 D3 7.9.0을 사용한다. 십자선 툴팁에 각 모델의 실제 x/원본값과 선택 시 스무딩 값을 표시한다. 데이터 범위 밖은 미기록으로 표시하고, 가장 가까운 관측값이면 실제 x를 명시한다. 마우스/터치와 키보드 좌우/Home/End/Escape를 지원한다. 빈 지표나 축으로 바꾸면 이전 툴팁을 지운다. 그래프 탐색 중 자동 페이지 갱신은 보류된다.

툴팁 구성 참고: https://docs.wandb.ai/guides/app/features/panels/line-plot/reference
D3 API 참고: https://d3js.org/d3-array/bisect , https://d3js.org/d3-selection/events

## 2026-09-27 화면 정리

화면 명칭은 노드/모델/프로젝트로 통일하고 캐릭터 비유 설명과 로고의 WHALE 글자를 제거했다. 그림은 유지한다. 상태 카드는 epoch만 표시한다. 현재 P2의 MLflow callback은 on_fit_epoch_end에서 0-based trainer.epoch를 기록하므로 완료 epoch=step+1로 표시한다. 다른 가져온 실험에는 이 변환을 적용하지 않는다. 모델 목록과 상세의 달리기는 최근(180초 이내) 조회한 running 상태를 나타내는 장식이며 배치 속도/진행률을 의미하지 않는다. 실패/완료/중단/검증/조회 오류 또는 오래된 관측에서는 멈춘다. reduced-motion 설정도 준수한다.
