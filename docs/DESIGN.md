# 제페토 · 고래 · 피노키오

현재 사용자 정의를 기준으로 한 도메인과 화면 설계다. 이전의 고래=학습 실행,
피노키오=프로그램 정의는 이 문서의 정의로 대체한다.

- **제페토**: 여러 학습 노드를 관리하고 모델의 성장을 지켜보는 주체.
- **고래**: 학습 노드. 데이터셋, 사용할 수 있는 모델 템플릿, 피노키오들을 품는다.
- **피노키오**: 고래 안에 소속되어 지속적으로 존재하는 모델. 번호와 이름을 가진다.
- **학습**: 피노키오가 목각인형에서 인간에 가까워지는 배움. 한 모델에 여러 작업이 쌓일 수 있다.
- **평가**: 배움의 결과를 확인하는 과정. 실제 평가 결과와 오류 분석을 성장 이력에 연결한다.
- **모델 템플릿**: 아직 피노키오 자체가 아닌, 모델을 만드는 설계·설정 계약.
- **카테고리**: 공 탐지·등번호 탐지·등번호 인식 등의 모델 분류. 노드를 대신하지 않는다.

## 탐색 구조

제페토 → 고래 → 피노키오 → 학습 작업 / 평가 기록.
고래 안의 탭은 피노키오 / 데이터셋 / 모델 템플릿 / 작업 이력이다.
왼쪽 메뉴는 고래들 / 전체 작업 / 예약 목록 / 설정이다.
상단 경로에는 실제 고래와 피노키오 이름을 표시한다.

처음 만든 모델은 1번 피노키오이며 번호는 로컬 카탈로그 전체에서 증가한다.
이름을 지정할 수 있지만 내부 id와 번호는 유지된다. 학습 작업을 다시 만들거나
예약으로 반복 실행해도 같은 피노키오에 연결된다. 새로운 피노키오는 별도로 만든다.
기존 실행에 모델 동일성을 증명할 정보가 없으면 별도 피노키오로 이관하며,
명시적인 상위 실행/예약 관계가 있는 기록은 같은 피노키오에 연결한다.
기존 확정 설정·데이터 버전·결과 파일은 변경하지 않는다.

## 성장 표현

학습 전은 목각인형, 학습 중은 배우는 중, 성공한 학습 이력은 한 걸음 성장으로 표현한다.
인간화 %는 계산하지 않는다. 학습 완료가 성능 향상을 의미하지 않으므로 평가 지표와 실패 장면을 함께 제공한다.
합성/모의 실행에는 실제 학습된 모델이 아니라는 표시를 유지한다.
작업 기록 상세에서는 고래 그림 대신 출발선과 도착 깃발 사이를 달리는 피노키오를 표시한다.
위치는 기록된 epoch / 전체 epoch를 기준으로 하며, 성공한 작업은 조기 종료 여부와 관계없이 도착지에 선다.
진행 수치가 없으면 출발선에서 기록 대기를 표시한다. 최근 실행 상태가 running일 때 달리며,
검증·조회 오류·180초 갱신 없음·연결 끊김·종료 시 정지한다.
`prefers-reduced-motion`에서는 애니메이션을 끈다.

## 노드 연결 범위

현재 기존 로컬 카탈로그는 **1번 고래**에 연결했다. 실제 Kubernetes 노드로 발견한 것이 아니다.
고래 추가는 노드 메타데이터 등록이다. 원격 연결·장치 발견·원격 파일 접근·노드 프로비저닝은 수행하지 않는다.
새 고래는 연결 전이며 실행을 차단한다. 원격 연결을 구성하지 않고 현재 호스트에서 대신 실행하지 않는다.
현재 UI에서 만들 수 있는 모델과 데이터는 로컬 고래에 속한다.

## Portainer 참고와 피노키오 목록

[Portainer Home](https://docs.portainer.io/user/home)의 환경 단위 탐색과
[Containers 목록](https://docs.portainer.io/user/docker/containers)의 검색·상태·정렬·상세 진입 배치를 참고했다.
고래가 환경의 문맥을 제공하고, 피노키오는 한 줄에 하나씩 쌓이는 가로 블록으로 표시한다.
블록에는 이름·모델/카테고리·현재 상태·최근 학습 기록·횟수를 열로 정렬한다.
검색, 상태 필터, 번호/최근 작업/이름 정렬을 제공하며 각 고래의 필터 선택은 세션에 유지한다.
좁은 화면에서는 블록 안의 항목이 아래로 재배치되지만 피노키오 목록은 항상 한 열을 유지한다.
기존 흑백 고래·피노키오 표현은 유지했다. Portainer의 API나 인프라에 연결하지 않는다.

## 고래 홈 · 제공된 Portainer 화면 반영

사용자가 제공한 Environments 화면을 기준으로 홈을 단일 노드 목록 패널로 바꿨다.
상단 검색·새로고침, 연결 유형/작업 상태/모델 분류 필터, 초기화·정렬을 배치한다.
고래는 전체 너비의 행으로 표시하며 왼쪽 고래 아이콘, 이름·호스트·등록된 연결 상태,
최근 작업 시각, 피노키오·데이터셋·템플릿·실행/대기/완료 수를 제공한다.
오른쪽은 고래 진입과 피노키오/데이터셋 바로가기다. 로컬 행은 연한 파랑으로 구분한다.
Up/실시간 연결/CPU/RAM 등 수집되지 않은 상태나 수치는 표시하지 않는다.
기존 홈의 별도 통계 카드와 설명 배너는 목록 중심으로 통합했다.
